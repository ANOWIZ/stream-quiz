# Квиз для прямого эфира

Приложение для ведущего и 2–6 игроков. Ведущий управляет вопросами и раундами, участники отвечают со своих устройств. Сервер синхронизирует игру через Socket.IO и сохраняет состояние в SQLite.

Личный проект Михаила Колпакова. Эта копия подготовлена для портфолио: рабочая база, загруженные пользователем медиа, пароли, резервные копии и документы ведущего исключены.

## Что реализовано

- Пульт ведущего и отдельный интерфейс игрока.
- Пять раундов с разными правилами и финал с интерактивной панорамой.
- Серверный подсчёт очков, таймеры и восстановление партии после перезапуска.
- Редактор вопросов, версий пакетов и библиотеки медиа.
- Проверка ответов и ограничение доступа к скрытым данным: игрок получает только разрешённую для текущей фазы информацию.
- Импорт и экспорт вопросов в JSON, проверка пакета перед стартом.
- Учебный набор заданий и локальная панорама со свободной лицензией.

Стек: React, TypeScript, Node.js, Express, Socket.IO, Prisma, SQLite, Three.js.

## Запуск

Нужен Node.js 22.12 или новее.

```powershell
npm ci
npm run dev
```

Команда создаёт локальный `.env` со случайными паролями, Prisma Client и пустую SQLite-базу с учебным набором. Откройте `.env`, чтобы узнать пароли; не публикуйте этот файл.

- Ведущий: `http://localhost:5173/host`
- Игроки: `http://localhost:5173/play`

Для проверки разных игроков используйте отдельные браузерные профили. Перед началом партии ведущий выбирает пакет и панораму финала. Учебные задания служат проверке механики игры.

## Проверки

```powershell
npm run db:generate
npm run typecheck
npm test
npm run build
```

Дополнительно: `npm run lint`, `npm run smoke`, `npm run test:e2e`. Браузерные тесты требуют установленного Playwright Chromium.

## Ограничения

Приложение рассчитано на одну игровую комнату с общими паролями ролей. Для доступа из интернета нужны HTTPS и собственные настройки сервера. Пакеты и пользовательские изображения исходной рабочей установки сюда не перенесены. В коде сохранена миграция первого раунда с десятью текстовыми вопросами и ссылками на источники; без соответствующей записи в старой базе она не запускается.

Источники и лицензии включённых материалов — в [ASSETS.md](ASSETS.md).
